1. مقدمة

هذا القالب «بداية» لا «منصة»: نسخة مستقلة لكل نشاط تجاري (مطعم/مقهى، متجر، عيادة، استوديو، معرض، مؤسسة). تُخصّص من ملف واحد للمحتوى واختيار واحد للسلوك، بينما البنية (عملة، محاكاة، حقول) تُضبط بالكود.

الهدف: أقل تكلفة وتعقيد ممكنين، مع أمان مناسب وتجربة استخدام بسيطة وقابلية واضحة للصيانة.

2. ما هو القالب؟

قالب ويب تجاري خفيف، قابل للتثبيت كتطبيق PWA، بواجهة عربية كاملة (RTL)، ولوحة إدارة لمدير واحد، وقاعدة بيانات SQLite واحدة.

  • يبدأ كنموذج لمطعم/مقهى، ويتحوّل إلى أي نشاط آخر باختيار واحد عند التهيئة (أنماط القدرات).
  • الـ API بسيطة ومنظمة؛ كل الردود بصيغة موحدة.
  • لا Composer ولا npm ولا services خارجية — توليد QR مضمّن (ISO/IEC 18004).
  • nginx هو الخادم المدعوم؛ Apache غير مدعوم.

3. ما يقدّمه

للزبون

  • صفحة تعريف (غلاف، نبذة، نقاط تميّز، أقسام، معرض صور، تواصل) من ملف واحد.
  • صفحة منتجات بالتصنيفات، بحث بسيط، صفحة تفاصيل عند الحاجة.
  • سلة وإتمام طلب (إذا كان النمط يتضمن طلبات) + متابعة حالة برمز QR.
  • PWA: تصفح catalog المحفوظ مسبقًا دون اتصال؛ تثبيت التطبيق.
  • وضعان: مع طلبات (🛒) أو عرض فقط (📖).

للمدير

  • لوحة إدارية: الرئيسية، التصنيفات، المنتجات، الطلبات، المواقع وQR، إعدادات العرض، الأمان والنسخ.
  • إنشاء/تعديل/حذف/ترتيب، رفع صور، توليد QR.
  • نسخ احتياطي (VACUUM INTO) واستعادة، تدمير النسخة والعودة للبداية.
  • تحديث دوري للطلبات (auto refresh) بدل WebSocket.

6. النشر على استضافة nginx

المتطلبات: nginx 1.18+ + PHP-FPM, PHP 8.1+ مع pdo_sqlite, mbstring. لا Composer/npm.

  1. ابنِ حزمة الإنتاج: php tools/build-release.php → dist/light-commerce-<ver>/
  2. ارفع محتويات dist/... إلى جذر الموقع.
  3. ثبّت deploy/nginx/site.conf (عدّل server_name/root/fastcgi_pass).
  4. صلاحيات: chown -R www-data:www-data storage app/uploads; chmod -R 775 ...
  5. ثبّت: php bin/console install --url=https://site --user=admin --pass="..." أو setup/index.php (ثم احذف setup/).
  6. اضبط storage/config/local.php: 'app' => ['base_url' => 'https://site'].
  7. فعّل HTTPS (جلسة Secure).
  8. تحقّق: php bin/console security:check.

7. حماية البيانات (الأهم)

القالب يشحن deploy/nginx/site.conf but installer does not install it on your server. تأكد ان storage/ غير قابل للتنزيل.

php bin/console security:check
curl -I https://your-site.com/storage/database/app.sqlite

إن لم تستطع تثبيت قواعد، انقل البيانات خارج جذر الموقع:

php tools/move-outside-webroot.php --yes
php bin/console security:check

14. QR والمواقع

  • نوعان: QR الموقع (طاولة 5) يحدد location في session; QR الطلب (token 32 chars) opens order info read-only.
  • مسح QR Location does not create order. Every successful submission creates independent order with unique id.
  • location can be required (server enforced, not just UI).
  • QR generation in admin (locations and orders) — no external paid service.
  • Location code prefix: match locationCodePrefix() (T/C/L).
  • Order token TTL: ORDER_TOKEN_TTL_MINUTES (14 days default).
'@

15. دورة حياة الطلب

الحالات الافتراضية: new → in_progress → completed + cancelled. كل حالة تنتقل إلى next محدّد (server enforced).

عند الإرسال (OrderService): verify input, verify products availability/prices, verify location, compute total on server, save order+items in single transaction, snapshot product name/price/qty, return order number. Idempotency-Key unique constraint prevents duplicate on retry. Cancel changes status, does not delete record.

16. لوحة الإدارة

الأقسام: الرئيسية (ملخص)，التصنيفات، المنتجات، الطلبات، المواقع وQR، إعدادات العرض. التخصيص الهيكلي (type, fields) not available in admin (by design). جلسة: HttpOnly + SameSite=Strict + Secure (HTTPS)، idle 2h، max 12h، renewal after login, 6 attempts then 15 min lockout. CSP stringent + nosniff + frame-ancestors none. All mutations require X-CSRF-Token.

18. النسخ الاحتياطي والاستعادة

  • لوحة: الأمان والنسخ → إنشاء نسخة الآن → تنزيل.
  • CLI: php bin/console backup → storage/backups/backup-YYYYmmdd-HHMMSS.sqlite (VACUUM INTO; safe during workload; perms 600).
  • استعادة: stop traffic (optional), copy backup to storage/database/app.sqlite, delete -wal/-shm, restart.
  • Cron يومي: 0 3 * * * cd /path && php bin/console backup > /dev/null.

24. المشاكل الشائعة


    

  • صفحة تحولك إلى setup: storage/config/local.php غير موجود. نفّذ install or open setup.
    • 

  • «حدث خطأ في الخادم» بعد التحديث: نفّذ php bin/console migrate.
    • 

  • رموز QR لا تعمل: تأكد base_url في local.php هو رابطك الحقيقي (https). جرّب الرابط تحت الرمز.
    • 

  • رابط مباشر /cart أو /order gives 404: needs rewrite to index.php (nginx try_files). بدونه app falls back to hash routing.
    • 

  • الصور لا تظهر: تأكد app/uploads writable (775) وأن الخادم allows display.
    • 

  • الطلبات لا تصل إلى اللوحة: HTTPS, api not blocked, storage writable.
    • 

  • الترميز العربي مشوّه: default_charset=UTF-8, files UTF-8 without BOM.
    • 

  • «لا يوجد اتصال» مع إنترنت: server error in api/index.php; inspect storage/logs/app-*.log.
